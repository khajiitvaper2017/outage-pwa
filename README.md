# Графік відключень — PWA

Простий Progressive Web App для перегляду графіка відключень світла (poe.pl.ua).

## Можливості

- Показує наступне відключення з зворотним відліком
- Список інтервалів по чергах (світло / можливе / відключення)
- Вибір черги
- Оновлення кожні 30 хвилин

## Встановлення

1. Розмістіть папку на HTTPS-хості (або `localhost`).
2. Відкрийте в Chrome / Edge / Firefox (Android або desktop).
3. «Додати на головний екран» / Install.
